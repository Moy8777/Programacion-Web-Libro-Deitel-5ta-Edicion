Ejercicio 2.10: Elemento o Atributo

  • a) html → Elemento (Etiqueta principal del documento)
  • b) width → Atributo (Define el ancho en imágenes, tablas, etc.)
  • c) href → Atributo (Especifica la URL en una etiqueta de enlace <a>)
  • d) br → Elemento (Etiqueta de salto de línea)
  • e) h3 → Elemento (Etiqueta de encabezado de nivel 3)
  • f) a → Elemento (Etiqueta para crear hipervínculos)
  • g) src → Atributo (Especifica la ruta de la imagen en <img> o script)

Ejercicio 2.11: Verdadero o Falso

  1. Falso. HTML5 no restringe el uso de mayúsculas ni minúsculas en las etiquetas. Sin embargo, se recomienda usar minúsculas por convención y buena práctica.
  2. Verdadero. Los documentos HTML5 pueden llevar tanto la extensión .html como la extensión .htm.
  3. Falso. La entidad de carácter para el símbolo de menor que (<) es &lt; (de less than). La palabra &less; no existe en HTML.
  4. Verdadero. Los elementos de lista <li> deben ser hijos directos de una lista ordenada <ol> o de una lista no ordenada <ul>.

Ejercicio 2.12: Completar oraciones

  1. Los comentarios de HTML5 comienzan con <!-- y terminan con -->.
  2. En HTML5, los valores de los atributos pueden ir encerrados entre comillas dobles (" ") o comillas simples (' ') (incluso sin comillas en casos simples, aunque no se recomienda).
  3. &amp; es la referencia a entidad de carácter para un signo &.
  4. El elemento <strong> (o tradicionalmente <b>) puede usarse para crear texto en negrita.

Ejercicio 2.13: Clasificación Elemento / Atributo

  • a) width → Atributo (Define el ancho de un elemento).
  • b) td → Elemento (Representa una celda de datos en una tabla).
  • c) th → Elemento (Representa una celda de encabezado en una tabla).
  • d) name → Atributo (Asigna un nombre a un elemento de formulario o control).
  • e) select → Elemento (Crea un menú desplegable de selección).
  • f) type → Atributo (Especifica el tipo de control de entrada, por ejemplo en <input>).
